DrawPath Studio 新手学习说明书

1. 为什么新手建议从「控笔 + 体块」而不是直接画完稿头像开始？

很多新手卡在「眼睛会了手不会」：线条抖、脸型左右歪、人体像塞棉花。每天只花 20 分钟，先在练习画板里叠着透视网格和体块底图练稳手腕、分清正面/侧面交界线，再去画人体动态与完整角色，进步速度会翻倍。

2. 两大秒懂自检神技：水平翻转 + 红线复盘

  • 水平翻转查崩坏（快捷键 H）：大脑看久了自己的画会自动“脑补对称”。点一下水平翻转，歪掉的下巴、跑偏的眼位、倾斜的重心会立刻暴露。
  • 外部软件 + 红线工作流：在 Procreate / Clip Studio Paint / SAI 画完后，点击画板里的「导入外部作品画红线」，它会自动放到低层并切到「正稿/红线层」与红色纠错笔，直接圈出透视与结构问题并存入画帖复盘！

3. iPad Apple Pencil & 数位板压感与倾斜侧锋贴士

  • 铅笔与马克笔原生响应 Apple Pencil 轻压灵敏度与倾斜侧锋：直立画清晰结构线，侧卧笔身即可顺滑扫出宽幅排线与阴影二分。
  • 在画板顶部勾选 「仅触控笔防误触」（且检测到 Apple Pencil 落笔后自动触发防误触保护），手掌可自然贴在 iPad 屏幕上画画。
  • 线条太抖时把 「抖动修正」 调到 4~7；鼠标绘图时画板会自动根据运笔速度模拟粗细出锋。

4. 添加到主屏幕变成独立离线 App (PWA)

在 iPad Safari 点击右上角「分享」→「添加到主屏幕」，或在电脑 Chrome / Edge 地址栏右侧点击「安装」，即可像本地软件一样全屏运行、离线练画。

进度、收藏视频与画帖均存在当前浏览器本地 IndexedDB 中，不会上传服务器；跨设备同步或重装浏览器前请导出 JSON 备份。

添加到主屏幕 / 安装桌面独立离线 App (PWA)

iPad / iPhone (Safari)

  1. 在 Safari 点击右上角「分享」→「添加到主屏幕」。
  2. 从桌面图标启动即可全屏无地址栏，配合 Apple Pencil 离线练习。

Windows / macOS (Chrome / Edge)

  1. 点击地址栏右侧「安装」图标即可作为独立窗口运行。
  2. 支持数位板 Wintab / Windows Ink 压感，离线可用。
