📘 DrawPath Studio 新手学习说明书

1. 为什么新手建议从「控笔 + 体块」而不是直接画完稿头像开始？

很多新手卡在「眼睛会了手不会」：线条抖、脸型左右歪、人体像塞棉花。每天只花 20 分钟，先在练习画板里叠着透视网格和体块底图练稳手腕、分清正面/侧面交界线，再去画人体动态、二次元或 Furry，进步速度会翻倍。

2. 两大秒懂自检神技：水平翻转 + 红线复盘

  • 🪞 水平翻转查崩坏（快捷键 H）：大脑看久了自己的画会自动“脑补对称”。点一下水平翻转，歪掉的下巴、跑偏的眼位、倾斜的重心会立刻暴露。
  • 🖍️ 外部软件 + 红线工作流：在 Procreate / Clip Studio Paint / SAI 画完后，点击画板里的「📂 导入外部作品画红线」，它会自动放到低层并切到「正稿/红线层」与红色纠错笔，直接圈出透视与结构问题并存入画帖复盘！

3. iPad Apple Pencil & 数位板压感设置贴士

  • 在画板顶部勾选 「仅触控笔防误触」，手掌就能自然贴在 iPad 屏幕上画画而不会误触线条。
  • 线条太抖时把 「抖动修正」 调到 4~7；想轻松画出最细笔锋可以把 「压感曲线」 设为「柔和」。
  • 没有数位板用鼠标时，画板会自动根据运笔速度模拟粗细出锋，同样能练控笔与结构推导！

4. 添加到主屏幕变成独立离线 App (PWA)

在 iPad Safari 点击右上角「分享」→「添加到主屏幕」，或在电脑 Chrome / Edge 地址栏右侧点击「安装」，即可像本地软件一样全屏运行、离线练画。

2. 安装为 iPad / 桌面独立 App (支持离线练习)

📱 iPad / iPhone (Safari)

  1. 用 Safari 打开本站（建议使用 HTTPS 或本地局域网地址）。
  2. 点击浏览器右上角的 「分享」 图标（方框带向上箭头）。
  3. 在菜单中往下滑，选择 「添加到主屏幕」 → 点击「添加」。
  4. 从桌面图标启动即可全屏无地址栏，配合 Apple Pencil 防误触顺滑练画！

💻 Windows / macOS (Chrome / Edge)

  1. 在地址栏右侧找到 「安装 DrawPath Studio」 图标（带加号的电脑/应用图标）。
  2. 点击 「安装」，网站会作为独立窗口程序出现在桌面或开始菜单。
  3. 支持数位板 Wintab / Windows Ink 真实压感，无网环境下也能查看教程与画图！
